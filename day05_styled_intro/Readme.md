Styled Personal Intro Page

📌 Project Goal
Transform the simple personal intro page (Day 1) into a **styled webpage** using CSS.

🛠️ Core Concepts Learned
1. **What is CSS?**
   - CSS (Cascading Style Sheets) is used to design and style HTML pages.
2. **Types of CSS:**
   - Inline CSS → Directly inside a tag (not recommended).
   - Internal CSS → Inside `<style>` tag in HTML.
   - External CSS → Separate `.css` file linked with `<link>` tag (best practice).
3. **Basic Properties Used:**
   - `background-color`, `color`
   - `padding`, `margin`
   - `font-family`
   - `box-shadow`, `border-radius`

🚀 How to Run
1. Open `index.html` in your browser.
2. Check how the styles from `style.css` change the look of the page.
