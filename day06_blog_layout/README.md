Simple Blog Layout (Flexbox + Navigation)

 📌 Project Overview
I built a **Simple Blog Layout** using **HTML + CSS Flexbox**, and added a **Navigation Bar** to make it look like a real blog website.  

The layout includes:
- ✅ **Header** with a **Logo Box**  
- ✅ **Navigation Bar** (Home, About, Blog, Contact)  
- ✅ **Main section** with Blog Posts (left) and Sidebar (right)  
- ✅ **Footer** with copyright  

---

 🎯 Learning Goals
- How to use **Flexbox** for 2-column layouts.  
- Creating **reusable blog post blocks** with CSS.  
- Designing a **Logo Box** inside the header.  
- Adding a **Navigation Bar** with hover effects.
