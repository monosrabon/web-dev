Responsive Blog Layout (Flexbox + Mobile Menu)

📌 Project Overview
I upgraded my **simple blog layout** to be fully **responsive**, adding a **mobile hamburger menu** using **JavaScript**.  

The layout includes:
- ✅ **Header** with a **Logo Box**  
- ✅ **Navigation Bar** with **hamburger toggle** for mobile  
- ✅ **Main section** with Blog Posts (left) and Sidebar (right)  
- ✅ **Footer**  

---

🎯 Learning Goals
- Make a layout **responsive** using **CSS Media Queries**.  
- Stack columns vertically on **smaller screens**.  
- Implement a **mobile hamburger menu** using **JavaScript**.  
- Understand **DOM manipulation** for interactive elements.
