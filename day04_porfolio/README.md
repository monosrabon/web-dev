📌 Project Goal
An extended **Portfolio Page** created using HTML only.  
It includes:
- Personal details
- About section
- Skills (with levels)
- Education
- Projects (academic + daily practice projects)
- Achievements
- Contact info (Email, GitHub, LinkedIn)

🛠️ Concepts Learned
- Structuring a longer webpage with multiple `<section>` tags
- Adding semantic elements like `<header>` and `<footer>`
- Using `<ul>` and `<ol>` for lists
- Linking to external resources (GitHub, LinkedIn)

🚀 How to Run
1. Open `index.html` in any browser.
2. Explore the portfolio sections.
3. Update links with your actual GitHub/LinkedIn.

🎯 Interview Note
This project demonstrates **how to build a structured personal portfolio website** using only HTML.  
It shows understanding of:
- Page layout
- Semantic HTML
- Organizing skills, education, projects, and contact info
