# 🌆 Image Overlay Project

## 📘 Overview
This project demonstrates the use of **CSS positioning** and **z-index** to create elegant image overlays with text and effects.  
It’s a simple yet professional web layout often used in modern websites, portfolios, and product showcases.

## 🧠 Concepts Used
- HTML `<div>` and `<img>` structure for layout  
- CSS `position: relative` and `absolute` for element placement  
- `z-index` for controlling the stacking order  
- Hover effects and opacity transitions for interactivity  

## 💻 Files
- `index.html` – Structure of the image and overlay text  
- `style.css` – Styling, positioning, and animation effects  

## 🚀 Purpose
Learn how to layer elements visually and design dynamic hover effects for engaging website components.
