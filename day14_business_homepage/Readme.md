🏢 Modern Business Homepage

📖 Overview
This project combines all HTML and CSS concepts learned so far to create a **modern, responsive business homepage**.  
It includes sections like Header, Hero, Services, About, and Footer — built using Flexbox and Media Queries.

🧠 Concepts Used
- **HTML5 Semantic Tags:** header, section, footer  
- **Flexbox Layout:** for responsive and clean alignment  
- **Media Queries:** for mobile-friendly design  
- **Box Model & Shadows:** for card styling  
- **Hover Effects & Transitions:** to add interactivity  
- **Images & Icons:** added to Service cards for a professional look
