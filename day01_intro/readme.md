📌 Project Overview
This is a simple personal introduction webpage built using **pure HTML**.  
The goal was to understand the **basic structure of an HTML document** and practice common tags.

🛠️ Concepts Learned
- Structure of an HTML page: `<!DOCTYPE html>`, `<html>`, `<head>`, `<body>`.
- Headings (`<h1>`, `<h2>`).
- Paragraphs (`<p>`).
- Lists (`<ul>`, `<li>`).
- Links (`<a>`).
