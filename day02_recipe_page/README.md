📌 Project Overview
A simple **Chocolate Cake Recipe Page** built with HTML.  
The project demonstrates usage of **lists, images, and tables**.

🛠️ Concepts Learned
- Ordered (`<ol>`) and unordered (`<ul>`) lists.
- Adding images with `<img src="..." alt="...">`.
- Creating tables with `<table>`, `<tr>`, `<th>`, `<td>`.
- Accessibility basics (using `alt` text for images).
