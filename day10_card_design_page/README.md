Card Design Page
📌 Project Overview

This project is about creating a professional card layout using HTML, CSS, and JavaScript.
Each card represents a topic (Web Development, Data Science, UI/UX Design, Cybersecurity) and includes:

An image
A title
A description
A button with a click interaction

The project mainly focuses on understanding the CSS Box Model and creating a responsive card grid layout.

🎯 Key Concepts Learned

HTML Structure
div containers to create cards.
img, h2, p, and button inside each card.
CSS Box Model
margin: space outside the element.
padding: space inside the element.
border: defines the outline.
box-shadow: creates a depth effect.
Responsive Grid
display: grid; with auto-fit and minmax() makes the cards adjust to screen size.
Hover Effects
Card lifts up slightly (transform: translateY(-10px)) and shows a stronger shadow.
JavaScript Interactivity
Button clicks trigger an alert() showing the card title.
Demonstrates DOM selection and event listeners.

🗂️ Project Files

index.html → Contains the structure of the card layout.
style.css → Styles the cards, layout, hover effects, and responsiveness.
script.js → Adds interactivity (button click alert).

🚀 How to Run

Download all files (index.html, style.css, script.js) into the same folder.
Open index.html in any browser.
Resize the browser window to see the responsive behavior.
Click on any Read More button to test the JS alert interaction.

📸 Output Preview

A responsive page with four cards.
Each card has an image, title, description, and button.

On hover → the card lifts up with a shadow.

On click → an alert displays the card’s title.
