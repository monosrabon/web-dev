💼 Advanced Contact Form 

A professional **Company Contact Page** built using **HTML, CSS, and JavaScript**, designed for startups or portfolio websites.  
This project demonstrates how to create a **responsive, functional, and modern contact form layout** with real-world UI design principles.



🚀 Features
- Two-column professional layout (Form + Company Info)
- Responsive design using **CSS Grid & Flexbox**
- Interactive form with **JavaScript validation**
- Modern, minimalistic theme with **logo box branding**
- Smooth hover and focus effects
- Mobile-friendly layout using media queries



🧠 Concepts Learned
| Concept | Description |
|----------|-------------|
| **HTML Forms** | Used to collect user data through input fields and textareas |
| **CSS Grid & Flexbox** | For creating a professional and flexible layout |
| **Media Queries** | To make the design responsive for all screen sizes |
| **JavaScript Validation** | Checks for empty fields and invalid emails |
| **CSS Variables & Box Shadows** | Adds branding consistency and modern style |
