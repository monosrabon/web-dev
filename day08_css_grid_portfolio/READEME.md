Portfolio with CSS Grid Layout

📌 Project Overview
I built a **Portfolio Page** using **CSS Grid Layout**.  
The page includes:
- ✅ Header (name + tagline)
- ✅ Navigation bar
- ✅ Sidebar (skills + quick bio)
- ✅ Main section (projects in responsive grid cards)
- ✅ Footer  

---

🎯 Learning Goals
- Understand **CSS Grid basics** (`grid-template-areas`, `grid-template-columns`, `grid-template-rows`).
- Create a **two-column layout** with sidebar + main content.
- Use **nested grids** for the projects section.
- Make the design **responsive** using `auto-fit` + `minmax()` and media queries.
