🛍️ Product Grid Page

📖 Overview
This project demonstrates how to create a **responsive product grid layout** using **CSS Flexbox**. It displays multiple product cards that automatically adjust based on screen size.

🧠 Concepts Used
- **Flexbox Layout:** `display: flex`, `flex-wrap`, `justify-content`, `align-items`
- **Card Design:** box shadows, hover effects, rounded corners
- **Responsive Design:** media queries for mobile adjustment
- **UI Elements:** product images, names, prices, and buttons
