📌 Project Overview

This project is a **Contact Form Page** built with HTML.  
It demonstrates how to use forms, input fields, radio buttons, checkboxes, and a textarea.

🛠️ Concepts Learned

- `<form>` element with `action` and `method`.
- `<input>` types: text, email, radio, checkbox.
- `<textarea>` for multi-line messages.
- `<button>` for form submission.
- `required` attribute to make fields mandatory.
