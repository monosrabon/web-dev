📱 Mobile-Friendly Layout

📖 Overview
This project demonstrates **responsive web design** using **CSS media queries**.  
The layout automatically adapts to desktop, tablet, and mobile screens for a better user experience.

🧠 Concepts Used
- **Media Queries:** Adjust layout for different screen sizes  
- **Flexbox:** Align content and sidebar side-by-side on desktop  
- **Responsive Navigation:** Stack links vertically on mobile  
- **UI Elements:** Header, main content, sidebar, footer
